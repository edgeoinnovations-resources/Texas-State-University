Taxonomy Coding Workbench

Code your own questions, lesson objectives or tasks with Jo and Bednarz's three-axis taxonomy. Each item gets a cell number from 1 to 24 and an integration level, and the tables below update as you go. Your work is saved in this browser and exports to CSV.

1Add items

Paste one item per line, or import a CSV with a text column (optional columns: id, group, concept, representation, cognitive, note). A group can be anything you want to compare: a textbook, a page location, pre or post.

2Code each item

Choose the highest-level spatial concept the item needs, whether it requires using or creating a representation, and the cognitive process it demands. Hints under each item flag verbs and concepts from the taxonomy's lists; they are prompts, not codes.

Coding reference: the taxonomy's categories

Concepts of space

Non-spatial. No spatial concept needed.

Spatial primitives. Place-specific identity, location, magnitude.

Simple-spatial. Distance, direction, connection and linkage, movement, transition, boundary, region, shape, reference frame, arrangement, adjacency, enclosure.

Complex-spatial. Distribution, pattern, dispersion and clustering, density, diffusion, dominance, hierarchy and network, spatial association, overlay, layer, gradient, profile, relief, scale, map projection, buffer.

Tools of representation

Non-use. The item can be answered without a representation.

Use. The item requires using or creating a map, diagram, chart, graph or photo.

Cognitive process (after Costa, 2001)

Input. Name, define, list, identify, recognize, recite, recall, observe, describe, select, complete, count, match.

Processing. Explain, analyze, state causality, compare, contrast, distinguish, classify, categorize, organize, summarize, synthesize, infer, make analogies, exemplify, experiment, sequence.

Output. Evaluate, judge, predict, forecast, hypothesize, speculate, plan, create, design, invent, imagine, generalize, build a model, apply a principle.

Cell number and integration

Cell = concept level × 6 + representation × 3 + cognitive level + 1, following Fig. 1 of the 2009 paper. Nine cells use a spatial concept and a representation: 10, 11, 16 (simplest); 12, 17, 22 (higher); 18, 23, 24 (highest). All other cells are "not integrated".

A numbering point to know before you cite cells. Table 3 of Jo & Bednarz (2011) labels two examples as simple-spatial yet assigns them cells 7 and 11, which Fig. 1 places at the spatial-primitive level. This workbench follows Fig. 1, so a simple-spatial, non-use, input item is cell 13. Check the papers and state which numbering you follow.

3Results

Counts cover fully coded items only.

4Compare groups

A chi-square test of whether the distribution differs across your groups, the same family of test the 2011 location study used. It needs at least two groups with coded items.

5Check agreement with a second coder

Export your CSV, have a second coder code the same items in their own browser, then load their export here. Items are matched by id.

6Export and manage

The CSV holds one row per item with codes as labels, plus cell number and integration level. The project file restores everything, including notes.

About this tool. A working tool built for this site on the coding scheme in Jo & Bednarz (2009). It is not an instrument the authors published. If you report results, describe them as an application of that scheme and cite the article.
